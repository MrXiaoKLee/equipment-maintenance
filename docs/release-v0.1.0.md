## 本机独立演示环境

本次复现位于 `.local/p6-20261015`：MySQL3307、Redis6400、后端8081、前端5174，独立数据库 `equipment_maintenance_demo`。正常开发环境仍使用MySQL3306、Redis6399、后端8080与前端5173，原业务数据未被初始化脚本覆盖。

演示账号密码在 `.local/p6-20261015/demo/demo-accounts.json`，业务清单在同目录demo-manifest.json。本地密码不放进本说明。五个演示账号保留启用，初始化及API验收会话已登出，浏览器测试登录已退出，业务数据保留供演示。

本机独立演示环境作为交付预览保留运行。其进程ID仅记录在 `.local/p6-20261015/processes.json` 供核对，不能在以后直接按旧PID停止进程；关闭时应先检查当前进程的命令行确实属于该独立目录。正常Windows MySQL/Redis服务不随独立演示关闭。源码包本身不包含这些进程、实例目录或本机密码，其他电脑依照local-setup重新初始化。
