## 保留的能力

保留admin、framework、system、common四个后端模块，以及用户、角色、菜单、部门/岗位关联、字典、系统配置、登录和操作日志。业务授权、人员候选、字典标签与权限配置仍依赖这些能力。

个人中心与头像上传、布局、分页、字典标签和Excel导出继续保留。登录日志使用的异步线程池也保留，它不是已移除的Quartz任务调度器。MIT许可证和第三方来源声明保留。

历史框架SQL继续作为固定基线保留；不删除数据库表或历史公告、任务、生成配置数据。v0.1.0源码包及标签是精简前的版本快照，当前源码以本次后续提交为准。
